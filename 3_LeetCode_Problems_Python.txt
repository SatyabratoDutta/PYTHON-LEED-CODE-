1. Two Sum — LeetCode #1

Problem:
Find two numbers whose sum equals the target.

Code:
class Solution:
    def twoSum(self, nums, target):
        seen = {}

        for i, num in enumerate(nums):
            complement = target - num

            if complement in seen:
                return [seen[complement], i]

            seen[num] = i

Example:
nums = [2, 7, 11, 15]
target = 9
Output: [0, 1]

Time: O(n)
Space: O(n)


2. Palindrome Number — LeetCode #9

Problem:
Check whether a number reads the same forward and backward.

Code:
class Solution:
    def isPalindrome(self, x):
        if x < 0:
            return False

        original = x
        reverse = 0

        while x > 0:
            digit = x % 10
            reverse = reverse * 10 + digit
            x //= 10

        return original == reverse

Example:
Input: 121
Output: True

Input: 123
Output: False

Time: O(log n)
Space: O(1)


3. Valid Parentheses — LeetCode #20

Problem:
Check whether brackets are correctly matched.

Code:
class Solution:
    def isValid(self, s):
        stack = []
        pairs = {
            ')': '(',
            ']': '[',
            '}': '{'
        }

        for char in s:
            if char in pairs:
                if not stack or stack[-1] != pairs[char]:
                    return False
                stack.pop()
            else:
                stack.append(char)

        return len(stack) == 0

Example:
Input: "({[]})"
Output: True

Input: "([)]"
Output: False

Time: O(n)
Space: O(n)
